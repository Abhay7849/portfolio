### Example 2: Job Post for Fixing Mobile Responsiveness & Layout Bugs
**Job Summary:** *"Our business website looks fine on desktop, but on mobile the navigation hamburger menu doesn't work and the cards are overflowing sideways."*

#### Your Proposal:
```text
Hi there,

I can fix your mobile navigation and overflow issues today. 

Horizontal scrolling and broken mobile menus are usually caused by fixed widths (`width: 100vw` or unconstrained containers) and z-index/JavaScript event listener conflicts on the hamburger button.

Here is what I will do immediately:
1. Inspect your layout using browser dev tools across iPhone and Android viewports to isolate the elements causing horizontal overflow.
2. Fix the hamburger toggle JavaScript to ensure smooth opening, closing, and proper ARIA accessibility.
3. Convert rigid fixed-width blocks to flexible CSS Grid / Flexbox media queries (`max-width: 100%`).
4. Perform cross-device testing to guarantee zero horizontal shift.

I am ready to jump in immediately and can have this resolved within a few hours.

Could you share the URL of the website so I can inspect the source code right away?

Best regards,  
Abhay Singh
```
