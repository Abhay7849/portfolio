# DevLens — Creative Freelancer Portfolio Template

A sleek, responsive personal portfolio template designed for developers, UI designers, and digital freelancers.

## Features
- **Dark & Light Mode**: Real-time theme switcher with persistent storage via `localStorage`.
- **Project Filter Gallery**: Interactive category filtering for Web Development and UI/UX projects.
- **Experience Timeline**: Career milestones, roles, and achievements display.
- **Minimalist Aesthetics**: Clean typography paired with subtle gradient accents.
- **Client Inquiry Form**: Contact form with instant status notification.
- **100% Mobile Responsive**: Fluid layouts on smartphones, tablets, and desktops.

## Technologies Used
- HTML5 (Semantic elements, accessibility tags)
- CSS3 (CSS Variables for themes, Flexbox, Grid, transitions)
- Vanilla JavaScript (Local storage theme persistence, category filtering, contact handling)

## How to Customize for a Client
1. Change personal name and role in `index.html` (search for `Alex`).
2. Add your own projects in the `<div class="works-grid">` section.
3. Update your work milestones in `<div class="timeline">`.
4. Connect social media links (GitHub, LinkedIn, Twitter) in the footer.
