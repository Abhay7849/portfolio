Technical Implementation Highlights

⚡ Min-Cash-Flow Algorithm

Uses a greedy approach with net balance priority to reduce complex N*(N-1) circular debts into the minimum possible settlement transactions.

🔒 Secure JWT Authentication

Stateless session management using JSON Web Tokens with bcrypt password encryption and protected Express middleware route guards.

🧾 OCR Receipt Scanner

Integrated Tesseract.js optical character recognition allowing users to upload photo bills and automatically suggest vendor, date, and amount.

📊 Analytics & PDF Export

Interactive Recharts spending visualizations with PDFKit export capability for generating structured expense summaries.
