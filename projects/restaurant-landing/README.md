# Savoria Bistro & Cafe — Restaurant Landing Page

A modern, high-converting restaurant and cafe landing page template built with semantic HTML5, CSS3, and vanilla JavaScript.

## Features
- **Hero Section**: High-resolution imagery with culinary statistics and call-to-action buttons.
- **Interactive Menu Filter**: Instant tab filtering (All, Main Courses, Starters, Desserts & Coffee) without page reload.
- **About / Heritage Section**: Highlights farm-to-table sourcing and master chef features.
- **Table Reservation Form**: Mobile-friendly booking form with instant confirmation feedback.
- **Fully Responsive**: Flawless display on mobile phones, tablets, and large desktop screens.

## Technologies Used
- HTML5 (Semantic markup, SEO meta tags)
- CSS3 (Flexbox, CSS Grid, CSS Variables, Custom Media Queries)
- Vanilla JavaScript (DOM manipulation, category filtering, form submission)

## How to Customize for a Client
1. Change restaurant name and logo in `index.html` (search for `Savoria`).
2. Update menu items, prices, and food photos in the `<div class="menu-grid">` section.
3. Update phone number, address, and operating hours in `<section class="reservation">`.
4. Replace Unsplash food images with the client's actual photography.
